# 沥泉科技 · Lichoin Technology

> 以技术创新为核心驱动力的创新型网络安全企业。

沥泉科技成立于 2022 年，员工规模约 100 人，技术人员占比超过 70%。公司坚持自主研发，围绕网络空间资产发现、风险检测、安全验证等关键场景，持续构建实战化安全能力与产品创新体系，为政府、金融、能源、运营商及各类企业客户提供专业、高效的安全解决方案。

## 自研体系

经过多年技术积累和项目实践，沥泉科技已形成覆盖安全工具、系统平台及安全数据资源的自主研发体系：

- **安全工具集**
- **系统平台**
- **安全数据资源**：身份认证凭证信息库、代码安全检测规则库等
